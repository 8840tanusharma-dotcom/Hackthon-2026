## Hackathon Project — Autonomous AI Creator

This project was developed with AI-assisted / vibe-coding workflows.

### Prompt 1 — Project Architecture
I am building an Autonomous AI Creator hackathon project. Help me design the architecture for a React frontend and Node.js/Express backend with AI agent creation, autonomous publishing, persistent memory, and an AI chat interface.

### Prompt 2 — AI Agent System
Help me implement an autonomous AI agent that has a name, domain/persona, memory, posts, and scheduled autonomous publishing.

### Prompt 3 — AI Chat
Help me add a chat interface where users can communicate with their autonomous AI agent. The chat should maintain conversation history and use the agent persona when generating responses.

### Prompt 4 — Gemini Integration
Help me integrate Google's Gemini API into the Node.js backend for generating AI responses. Include proper error handling and environment-variable based API key configuration.

### Prompt 5 — Persistent Memory
Help me implement persistent storage for agents, published posts, and chat history so the application can remember data.

### Prompt 6 — Frontend UI
Help me build a modern dark futuristic dashboard UI for the autonomous AI creator, including agent information, statistics, published posts, and an AI conversation panel.

### Prompt 7 — Chat Scrolling Fix
The chat messages in my dashboard are not scrolling correctly. Help me fix the CSS so the chat area has a fixed height and its messages can scroll vertically without affecting the rest of the dashboard.

### Prompt 8 — Deployment Debugging
My deployed frontend can reach the backend, but the AI chat is failing after deployment. Help me debug the frontend API URL, backend deployment, CORS, environment variables, and agent persistence.
